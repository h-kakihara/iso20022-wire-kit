# Contributor Covenant Code of Conduct

## Our Pledge

We as maintainers, contributors, and sponsors pledge to make participation in our open-source financial infrastructure projects a harassment-free, constructive, and technically rigorous experience for everyone.

## Standards of Behavior

* Focus discussions on protocol accuracy, cryptographic correctness, and reproducible test cases.
* Never share live production banking credentials, real customer IBANs, or personally identifiable financial records in issues or pull requests.
* Respect differing regulatory and regional payment scheme requirements across jurisdictions.

## Unacceptable Behavior

* Publishing private security vulnerabilities publicly prior to coordinated disclosure (see `SECURITY.md`).
* Harassment, personal attacks, or trolling in code reviews or issue threads.
* Submitting obfuscated code or introducing unapproved third-party runtime dependencies.

## Enforcement

Instances of abusive or unacceptable behavior may be reported via GitHub profile channels to `@h-kakihara`. All reports are reviewed confidentially and acted upon promptly.
